# Uitgangspunten

Bij het maken van het Logisch Model gebruiken we de volgende uitgangspunten

**Uitgangspunt:** Het Logisch Model is een model conform het [[MIM12]]
beschouwingsniveau 3.

**Uitgangspunt:** Het Logisch Model is in lijn met het [[CIm_VTH_FLo]].

**Uitgangspunt:** Bij de ontwikkeling van het Logisch Model is sluit aan op
op het model Inspectieview zoals beschreven in [[BaselineCSV]]. Hiertoe is een
mapping gemaakt die is beschreven in Appendix A. Daar waar de mapping
niet volledig is wordt dat in de Appendix vermeld.

**Uitgangspunt:** Het ontwikkelde model sluit aan op het GIR.

**Uitgangspunt:** Het Logisch Model bevat voldoen informatie om een
json schema te genereren volgens [[UML2JSON]].
